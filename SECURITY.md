# Security Policy

## Reporting a Vulnerability

Please send any suspected vulnerability report to security@netboxlabs.com.
Do not open a public GitHub issue for security problems.

## Scope

This repository contains the NetBox DCIM provider for NVIDIA Config Manager
and its deployment tooling. Issues in NetBox itself belong to the
[NetBox security policy](https://github.com/netbox-community/netbox/security/policy),
and issues in NVIDIA Config Manager to
[NVIDIA's security policy](https://github.com/dsx-ai-factory/nv-config-manager/security/policy).

## Supported Versions

Only the latest release receives security fixes.
